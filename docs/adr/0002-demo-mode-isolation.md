# Demo Mode แสดงเฉพาะเมื่อไม่ระบุสตรีมเมอร์

> **Status: superseded (ยังคงหลักการ "ห้ามข้อมูลปลอมบนหน้าจริง" อยู่เต็มร้อย)** — ในการทำหน้าแรกเป็นทำเนียบสตรีมเมอร์ ไม่มีเส้นทางใดที่เข้าถึงหน้าโดเนตโดยไม่ระบุสตรีมเมอร์อีกแล้ว (เข้าผิดจะถูกส่งกลับไปทำเนียบ) Demo Mode จึงถูกถอดออกทั้งก้อน หลักการเดิมที่ยังผูกพันอยู่: หน้าของสตรีมเมอร์แสดงเฉพาะข้อมูลจาก API เท่านั้น ไม่มีข้อมูลตัวอย่างหลุดเข้าไปเด็ดขาด

---

## ประวัติการตัดสินใจเดิม (ก.ย. 2026)

ก่อน redesign หน้าโดเนตมีข้อมูลปลอมปนอยู่เกือบทุกจุด (leaderboard ตัวอย่าง, จำนวน follower ปลอม, badge PARTNER, แถบเป้าหมาย hardcoded 78%) แม้แต่บนหน้าของสตรีมเมอร์จริง — ซึ่งสร้างความเข้าใจผิดกับผู้บริจาคได้

เราตัดสินใจแบ่งชัดเจน: ข้อมูลตัวอย่าง (Demo Mode) แสดง **เฉพาะ** เมื่อเปิดหน้าโดเนตโดยไม่มี `?u=username` เท่านั้น หน้าของสตรีมเมอร์จริงแสดงข้อมูลจาก API เท่านั้น และถ้ายังไม่มีข้อมูลให้ใช้ empty state ที่ดีต่อสายตา ห้ามแต่งข้อมูลปลอมเด็ดขาด

**Considered Options**: ลบ mock ทิ้งทั้งหมด / เก็บ mock ทุกที่ — ถูกปฏิเสธเพราะอย่างแรกทำให้ไม่มีหน้าสาธิตตัวเองแบบสมบูรณ์ อย่างหลังไม่ production-ready

**Consequences**: หน้าของสตรีมเมอร์ใหม่ที่ยังไม่มีโดเนตจะดู "ว่าง" จริง ๆ ด้วย empty state — นี่เป็นพฤติกรรมที่ตั้งใจ ไม่ใช่บั๊ก
