# โฟลว์โดเนตบนหน้าเดียว โดยเก็บ `/pay/:id` เป็น fallback

ในการ redesign หน้าโดเนต (ก.ย. 2026) เป้าหมายคือลดจำนวน step ของผู้บริจาคให้เหลือน้อยที่สุด เราตัดสินใจให้ QR PromptPay แสดงแบบ in-place swap ในหน้าโดเนต (ฟอร์มค่อย ๆ เปลี่ยนเป็นแผง QR + countdown ใน URL เดิม) แทนการเด้งไปหน้าใหม่

อย่างไรก็ตาม route `/pay/:id` **ไม่ถูกลบ** — ยังใช้เป็นหน้า fallback สำหรับกรณี refresh หน้า, ส่งลิงก์ไปสแกนข้ามเครื่อง, หรือเปิดจากแท็บอื่น เพราะ QR ต้องรอดจากทั้งสามกรณีนี้

**Considered Options**: wizard 2 step / modal ทับหน้า / หน้าแยกแบบเดิม — ถูกปฏิเสธเพราะเพิ่ม step หรือตัดการมองเห็นบริบทหน้าโดเนต

**Consequences**: ต้องมี UI สองที่ที่เรนเดอร์สถานะ Donation เดียวกัน (แผง inline และหน้า `/pay/:id`) — logic ตรวจสถานะ/นับเวลาถอยหลังต้องใช้ร่วมกัน ไม่ใช่ copy สองชุด
